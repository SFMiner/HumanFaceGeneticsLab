# Human Face Genetics Simulator Manual

## Overview
This simulator lets learners explore simplified human genetics through recombination. You can generate humans, select parents, explore allele combinations, and observe phenotypes in the Punnett Square and offspring results.

## Core Panels
- **Human Library**: Stores generated humans. Use the search and filters to find them. Click the heart to favorite. Click the trash icon to delete.
- **Recombination Area**: Drag two humans into the parent slots to recombine. You can drag allele chips to override specific genes for a constructed parent.
- **Allele Bank**: Shows allele pairs for active genes. Check the gene checkbox to include it in the Punnett Square.
- **Punnett Square**: Shows genotype combinations for the selected genes (size depends on how many genes are included).
- **Offspring Result**: Shows a face and visible traits for the current offspring. Click **Save to Library** to name and save it.

## Tutorial
On first run, a tutorial can guide you through generating humans, selecting parents, using allele chips, and recombining. Choose **Skip Tutorial?** if you want to skip it.

## Recombination Workflow
1. Click **+ Generate Random Human** to add a human to the library.
2. Drag a human to each parent slot.
3. (Optional) Drag allele chips to adjust a parent genotype.
4. Click **Recombine** to generate an offspring.
5. Click **Save to Library** to name and store the offspring.

## Class settings (for teachers)
On the website there is no Teacher Mode button and no password. Instead, a teacher gives the class a link that sets up the game, for example to start everyone on one level, show only ratios in the Punnett square, or give every student the same results. Build the link on the game's page on the website (under "For teachers") and post it for your class. When a link sets things up, a green banner at the top lists the settings. The settings last for that visit only; opening the game without the link gives the standard game.

## Levels and Purpose
1. **Eye Color Basics**: Introduces TYR, OCA2, and HERC2 to show dominance and epistasis in eye color.
2. **Eye Color Advanced**: Adds TYRP1 for eye intensity variation.
3. **Skin Tone**: Adds SLC24A5 and SLC45A2 to model skin pigmentation.
4. **Hair Color**: Adds MC1R (red hair pathway) and TYRP1 effects on hair color.
5. **Complete Human Variation**: Uses all genes, including hair texture (TCHH) and albinism (ALB), to show full trait combinations.

## Tips
- Check more genes to expand the Punnett Square (e.g., 3 genes makes an 8x8 grid).
- If the Punnett Square is too dense, uncheck some genes or reduce the max genes per cross in Teacher Mode.
- Use recombination terminology in classroom materials and screenshots.
